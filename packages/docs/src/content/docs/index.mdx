## A backend for marketing, sales and customer success

<CardGrid>
  <Card title="Bring your own agents" icon="star">
    Connect through MCP, the command line, or REST. Onboard any agent: Claude Code, Instinct, Dots, Grok Bot. Your workflows run where you choose; Vibase keeps the business records.
  </Card>
  <Card title="Delegate with control" icon="approve-check">
    Grant reads, proposals, or direct writes per resource. Keep provider credentials inside Vibase and review actions when needed.
  </Card>
  <Card title="Own your deployment" icon="setting">
    Run one workspace on Cloudflare Workers and D1 in your own account, with your own API URL and authentication.
  </Card>
  <Card title="Build your own experience" icon="pencil">
    Use your agents conversationally or build dashboards and internal tools on the same API. There is no required CRM frontend.
  </Card>
</CardGrid>
