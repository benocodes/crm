# approvals-app

A small static page for reviewing what agents have proposed to a Vibase instance: it lists action requests and approves or rejects them. An example app, not part of the CRM. Documentation: https://docs.vibase.ai.

Build, configuration and deploy: [DEVELOPMENT.md](https://github.com/benocodes/crm/blob/main/packages/approvals-app/DEVELOPMENT.md).
