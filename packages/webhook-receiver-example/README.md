# webhook-receiver-example

A copyable Cloudflare Worker that turns a Vibase webhook into a Workflow: it verifies the signed event, reads the message and proposes a reply for approval. Documentation: https://docs.vibase.ai.

Setup, deploy and tests: [DEVELOPMENT.md](https://github.com/benocodes/crm/blob/main/packages/webhook-receiver-example/DEVELOPMENT.md).
